Type-Coercion Helpers & Pydantic Fix NEW

Applied in update_project_supplier() in atoms_projects_service.py — handles numeric DB columns regardless of whether the frontend sends a string or a number.

_to_int(v)
product_monthly_capacity (int)
"50" or "50 MT" or 50 → 50
_to_decimal(v)
target_cost, manufacturing_price (decimal)
"200" or "200.5" or 200 → 200.0
_to_bit(v)
manufacturer_license_check (bit)
"yes"/"no"/"1"/"0"/"true"/"false" → True/False

Pydantic fix — Bug #5

type="number" HTML inputs send JSON numbers. Pydantic v2 won't auto-coerce int or float to str, causing 422 Unprocessable Entity on supplier update. Fixed by typing all numeric fields as Optional[Union[str, int, float]] in UpdateProjectSupplierPayload.

audit_master Deduplication Query NEW

The audit_master table has duplicate rows (INSERT script ran twice). Without dedup, 12 rows are returned instead of 6. Fixed in get_project():

SELECT am.* FROM dbo.audit_master am INNER JOIN ( SELECT MIN(audit_item_id) AS audit_item_id FROM dbo.audit_master WHERE is_active = 1 GROUP BY audit_item_name ) dedup ON am.audit_item_id = dedup.audit_item_id ORDER BY am.audit_item_id ASC
Always returns exactly 6 items. Safe to keep even after duplicate rows are cleaned from the DB.

Auto-Creation Logic — Silent Parent Records

_get_or_create_demand_generation(conn, project_id)

Triggered when adding Sales Reachout or Digital Marketing.

  1. Check if project_demand_generation exists → return demand_id
  2. If not → find finalized supplier (fallback: any supplier) → INSERT with demand_source='MANUAL', created_by=1 → return new demand_id
_get_or_create_agreement(conn, project_id)

Triggered when adding Production Detail or Order.

  1. Check if project_manufacturing_agreement exists → return agreement_id
  2. If not → find finalized supplier → INSERT stub with agreement_status='DRAFT', created_by=1 → return new agreement_id
upsert_audit_detail() — project_supplier_audit header auto-creation NEW

Triggered on any audit checkbox toggle or note save.

  1. Find finalized supplier (fallback: any supplier)
  2. Check if project_supplier_audit exists for project_id + supplier_id → use it
  3. If not → INSERT with audit_status='IN_PROGRESS', created_by=1
  4. Upsert project_supplier_audit_details row for the audit_item_id

Key Design Decisions

Notion-style inline editing (no modals)Fast, in-context editing — matches requested UX pattern across all stages.
Click-any-field to edit (no Edit button)More intuitive — user clicks directly on the data they want to change. Whole card enters edit mode together; Save/Cancel visible in header only while editing.
Status badge as cycle buttonPrevious <select> was not recognizable as interactive. Visible pill with ▾ cycles Pending → In Progress → Completed → Pending with spinner during API call.
Supplier dropdown as fixed portalposition:fixed + getBoundingClientRect prevents clipping inside overflow-x-auto table containers.
Audit notes: controlled input + explicit ✓onBlur fired before the ✓ click registered, discarding the note. Explicit ✓ button removes the race condition entirely.
audit_master dedup via MIN GROUP BYDB has duplicate rows (INSERT ran twice). Query guarantees exactly 6 audit items always returned.
_to_int / _to_decimal / _to_bit helpersAccepts strings or numbers from frontend. Prevents SQL conversion errors for int/decimal/bit DB columns regardless of what the input sends.
Pydantic Union[str, int, float]type="number" inputs send JSON numbers; Pydantic v2 won't coerce to str → 422 errors. Optional[Union[str, int, float]] fixes this.
manufacturer_license_check as Yes/No dropdownDB column is bit — free text caused SQL errors. Dropdown enforces valid values. API returns Python bool → frontend maps true→"yes", false→"no".
Component split into atoms/ sub-componentsMain file hit 2022 lines — unmanageable. Split into ~694 orchestrator + 4 focused stage files + shared types.ts. No logic changes.
Parent records auto-created silentlydemand_source and supplier_id are NOT NULL in parent tables. Backend creates them transparently on first child insert — user never sees it.

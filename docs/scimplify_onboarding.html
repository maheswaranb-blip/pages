What is Scimplify?

Scimplify is a chemistry & pharmaceutical supply-chain platform. It connects customers (pharma/biotech companies who need molecules made or research done) with suppliers (research labs and manufacturers who do the work), with Scimplify's internal team orchestrating everything in between.

One-liner: Think of it as the operating system for chemical project management — customers post requests, the platform finds and scores the best-fit lab or factory, manages proposals, and tracks delivery.
🔬
R&D
Research & development of a new molecule or compound. Handled by CROs via IONS.
🏭
CMO
Contract manufacturing — scaling up production of a known compound. Handled by manufacturers via ATOMS.
⚗️
CDMO
Full service — R&D and manufacturing combined. Uses both IONS (R&D stage) and ATOMS (manufacturing stage).

Stage Color System

Throughout the platform, timeline stages use a consistent color language. Learn this once — it applies everywhere.

Green — Stage is complete
Yellow / Amber — Stage is in progress / pending action
Grey — Stage not yet started
Example in CMO flow: When Stage 3 (Process Finalized) is complete (green), Stage 4 (Partner Shortlisted) turns Yellow. When Stage 4 is complete (green), Stage 5 (Commercial Proposal) turns Yellow with the header "Commercial Proposal Getting Ready." Each completed stage automatically activates the next one.
Expert call states: If the customer scheduled the call from the form → Stage 2 shows Green. If they didn't schedule a call yet → Stage 2 shows Yellow with a "Consulting Call Pending" Calendly widget to book one.

What is a "Project"?

A project is created after a customer accepts a proposal and places a PO. It is the central record that all three parties (Customer, Admin, Supplier) share under one ID.

One Project = One Customer + One Product + One Business Program (R&D / CMO / CDMO)

Same customer, same product, ETA revisedEdit existing project data

3 ways to create a project: Admin can click "Start Project" from (1) the Supplier Proposal page, (2) the Customer Request page, or (3) the Projects Dashboard directly. All three open the same unified popup. Fields pre-filled from linked proposals/requests are shown with a "Fetched" indicator but remain editable.

Project Detail Page Structure

Every project detail page (in all portals) is organized into 4 headers. The content in Header 3 changes based on project type. There is also a special Execution Fit section visible only to customers.

4 Standard Headers (All Project Types)
H1
Project Details (common to all types)
Product Name, CAS Number, Total POs expected, Quantity + Unit (multiple pills supported), Internal POC name/email, Customer POC name/email, Created Date.
H2
PO Details — Supplier View ⚠ Never shown to customer
Release Date, ETA, Timeline, Quantity, Price Per Unit (currency + number + unit), Order Value, Specs, Packaging Type, Payment Terms. Contains sensitive pricing — customer never sees this.
H3
Scope / Requirements (varies by project type)
R&D & CDMO: Product Image, Proposal Code, Submitted Date, RFQ Date, Quantity ETA (per-pill), Delivery Date, Appearance, Grade, Application, ROS file.
CMO only: Yield, Impurity, Assay (with dynamic "by [Tool Name]" sub-label once tool selected from dropdown).
H4
Terms (common to all types)
Payment Terms section: Payment Method, Payment Terms (synced with H2), Note. General Terms section: free-form contractual notes. Edits in H4 sync back to H2 automatically.
⭐ Execution Fit Section — Customer View Only

This section is shown only to customers on SciNode. Admin fills it in Nucleus to give the customer confidence in the chosen lab/plant. It is never shown to suppliers.

R&D Project
Shows Lab Details: Lab Name/Location, Lab Image, Fit Score (shown as %), Capability Highlights (bullet list, each up to 200 chars).
CMO Project
Shows Plant Details: Plant Name/Location, Plant Image, Fit Score (%), "Why This Manufacturer?" highlights list.
CDMO Project
Shows all three: Lab Details + Pilot Plant Details + Plant Details. Each has its own image, fit score %, and highlights.

Who Sees What — Privacy Rules

The platform carefully controls what each stakeholder can see and edit. This protects pricing from customers and execution details from irrelevant parties.

H2 — Supplier PO Details (pricing, ETA, order value) ✓ Full edit ✓ Edit ✗ Hidden entirely
Customer PO Details (PO number, release date, ETA) ✓ Full edit View only View only (own PO)
H3 — Scope / Requirements ✓ Full edit ✓ Edit View only
H4 — Terms ✓ Full edit ✓ Edit View only
Execution Fit (lab/plant image, fit score, highlights) ✓ Full edit ✗ Not shown ✓ View only
Key privacy rules: Customer never sees supplier pricing (Price Per Unit, Order Value). Supplier never sees the Execution Fit section. Customer PO ETA and Timeline are synced from the Supplier's ETA — if admin changes supplier ETA, it auto-updates customer's view too.

End-to-End Project Lifecycle

Every project follows this journey — from a customer filling a form to active delivery being tracked by all parties.

1
Customer submits a request on SciNode
Picks a request type (RFS, RFQ, CMO, CDMO, R&D, Consultation), fills the form, optionally schedules a call via Calendly. Both "scheduled call" and "no call" flows work — the system handles both states with different stage colors.
2
Admin reviews → Expert assigned → Call scheduled
Admin (in Nucleus) reviews request. Assigns an expert (Production Engineer). Expert call happens via Calendly. This is the "Talk to Our Expert" stage.
3
Process Finalized (admin fills details after call)
For CMO: admin fills 4 tabs — Project Brief, Key Challenges, Required Equipment, Project Scale. For CDMO/R&D: Lab & Plant matched — best-fit CRO selected with Partner Name, Type, Location, Compliance (GLP/Non-GMP), Selection Rationale, Capabilities, Equipment.
4
Partner shortlisted / Research partner identified
Admin selects best-fit supplier. Match Score is calculated and shown to customer (see Section 10). Competitive Advantages (Track Record, Regulatory Compliance, Cost Efficiency, Timeline Assurance) are added by admin.
5
Commercial Proposal sent to customer
Admin publishes proposal. Customer sees: Project Title, Research Partner, Lead Time, Currency, Price per Quantity table, Scope of Work (Study Type, Method, Sample Quantities), Specs (Quality Attributes, ROS, Supporting Docs), Payment Terms, Shipment Terms.
6
Customer accepts, revises, or declines
Customer can: Accept Proposal (final — pricing locked), Request Revision (must pick: Price / Scope / Timeline + free text comment — request goes to "Revision Requested" status), or Decline (mandatory reason required). Revised offers show a "New Quote Available" badge.
7
Customer uploads PO → Request Closed
After accepting, customer enters PO Number and uploads PO document. PO Release Date is auto-captured (not manually set). Request status → "Closed". PO upload is only enabled after closure.
8
Admin creates the Project
Admin clicks "Start Project" (from Supplier Proposal page, Customer Request page, or Projects Dashboard). Selects type → fills headers → submits. System creates Master Project ID (e.g. PRJ-2026-001), sends emails to both supplier and customer, marks request and proposal as "Project Created".
9
Active execution — all parties track the same record
Supplier (IONS/ATOMS) updates milestones and stages. Admin orchestrates in Nucleus. Customer tracks progress in SciNode (view-only). New POs can be added at any time without creating a new project row.

Match Score Systems

There are two different match score formulas — one for selecting a CRO (for R&D/CDMO) and a different one for selecting a CMO (for manufacturing). Both are calculated by admin and shown to the customer as a percentage.

🔬 CRO Match Score
For R&D and CDMO projects
🧪 Chemistry / Product Match
45%
Exact/Similar Product History (25) + Chemical Class Experience (10) + Scale & Complexity Fit (10) = 45 pts
Formula: (History + Class + Scale) / 45 × 45%
⚙️ Equipment Match
20%
All equipment available=20 · Most available=12 · Major gaps=6 · None=0
📍 Location Match
20%
Preferred=20 · Acceptable=12 · Non-preferred=6 · Not acceptable=0
Total = Chemistry (45%) + Equipment (20%) + Location (20%) = max 85%
Note: match score is NOT shown for Exploratory R&D requests — only for defined objectives (Product Dev, Scale Up, etc.)
🏭 CMO Match Score
For CMO (manufacturing) projects
⚙️ Equipment Match
45%
Formula: (Equipment available ÷ Equipment required) × 45
🧪 Reaction Match
35%
Formula: (Reactions available ÷ Reactions required) × 35
Only applies to Tech Transfer sub-type (not Unit Operations)
📍 Location Match
20%
Preferred=20 · Acceptable=12 · Non-preferred=6 · Not acceptable=0
Total = Equipment (45%) + Reaction (35%) + Location (20%) = max 100%
Admin adds all scoring details. Customer only ever sees the final percentage — not the breakdown.
